## 與原簡報的主要差異

1. **對照 2026 選手手冊補齊規則**：每位選手僅限一輛官方補給車、僅穿背心的陪跑員／補給員可接觸選手、靜態補給四要件、草坪頭→塔塔加補給車禁行區、11:30 後可上山接關門選手、罰則、申訴、接駁。
2. **T2 檢錄清單補齊**：原表缺「手機、GPS 追蹤器、背包掛燈」，依手冊強制裝備補上；新增陪跑員強制裝備。
3. **特殊需求袋**：手冊有黑袋（塔塔加 86 km）與紅袋（草坪頭 56 km）兩個，原表只有夫妻樹；草坪頭的補給方式與 2026 規定衝突，列入待確認。
4. **視覺化**：以 2025 大會 GPX 繪製自行車高度剖面與路線圖；跑步段剖面依路標海拔繪製（示意）；比賽日時間軸含日出日落；照片取自 2025 FXT 選手手冊（大會官方影像，僅供團隊內部使用）。
5. **工作工具**：車輛任務板、兩件背心人選、緊急聯絡表留白供會議填寫。
6. **選手換裝指示**：清境換 T 恤、翠峰換衣斗篷換跑褲、鳶峰套長褲外套手套開始走路、跑步段補給葡萄（第 6、7、14、21–23、27 頁）。

## 重新產生簡報

```bash
cd deck/src
npm install
npm run all      # 產生圖示與背景 → 產生剖面／地圖 → 產生 ../2026_FXT_補給作戰計畫.pptx
```

- `gen_assets.js`：山景背景（SVG）與 react-icons 圖示 PNG。
- `gen_charts.js`：由 `data/bike_profile.csv`（2025 大會 GPX 每 0.2 km 取樣）繪製剖面與地圖。
- `build_deck.js`：版面與全部文字內容。
- 字型使用「Microsoft JhengHei」；Mac 會自動以 PingFang TC 代替。

## 注意事項

- 回程地標（合社、豐丘、水里坡、埔里高工）的「約」里程為 GPX 推估，請以車隊實際路線為準。
- 清境檢查點里程（17.5 vs 19 km）、T2 實際位置、最後檢查點名稱等原簡報待確認事項仍保留在第 28 頁。
- 手冊載明：所有賽事資訊以賽前說明會（11/12）公布內容為最終依據。
